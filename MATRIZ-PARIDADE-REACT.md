# Matriz Django Admin × React — 26/10/2026

Escopo: código do ZIP recebido. O legado permanece em `/superadmin-legacy/` (global) e `/admin/` (lojista); o React principal continua em `/painel/`, com host e permissões separados. Nenhuma publicação ou alteração de banco externo foi executada.

## Evidências e limites

- Suíte crítica: 900 testes, OK, 25 pulados. Execução local com SQLite isolado e SSR Node ativo; não equivale ao teste PostgreSQL em Docker.
- Casos de conclusão: 14 testes (incluídos na descoberta ampla); 2 de concorrência dependem de PostgreSQL. Reexecução focada após habilitar cobrança no teste de criação de loja.
- React: 57 testes, OK; build TypeScript + Vite administrativo, público e SSR aprovado.
- Scripts operacionais: 13 testes, OK. `makemigrations --check --dry-run`: nenhuma alteração detectada.
- Asaas, e-mail e Evolution nas operações testadas usam mocks. Não foram feitos disparos ou cobranças reais.
- Os logs desta entrega estão em `qa-results/react-completion/` (os resultados anteriores permanecem em `react-admin-parity/`).
- As linhas de cadastro abaixo não são declaradas integralmente validadas: listagens e esquemas de criação foram testados para todos os recursos globais; a regressão dos lojistas foi executada, mas não houve inspeção manual de cada campo/inline/ação em navegador com dados reais.
